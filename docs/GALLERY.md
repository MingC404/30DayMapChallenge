# Gallery maintenance

The retained Pages configuration is `main` / `docs` (`01/pages_config.json`). The existing site is generated by `scripts/prepare_gallery.cjs` from `scripts/gallery_entries.json` and `scripts/gallery_template.html`; no new website or hosting service was created. Paths are tested under `/30DayMapChallenge/`.

The collection contains finished Days 01–06 and 08–13. Day 07 has only a placeholder and is omitted. The public-ready interactive maps are Days 01, 02, and 10. Day 13 is interactive locally but awaits data-use clearance; its public card links to a status page, not a map. Only the local-review variant displays its actual cover and interactive link.

## Build and preview

```powershell
node scripts/prepare_gallery.cjs
node scripts/serve_gallery.cjs
```

Open `http://127.0.0.1:8026/30DayMapChallenge/`. For the private local review, first run `node scripts/prepare_gallery.cjs --local-preview`, then `node scripts/serve_gallery.cjs --local-preview`. This explicit flag mounts `13/` on loopback; without it restricted assets are not served. The local index is ignored `.work/gallery-preview/index.html`, with no copied private map payload.

## Assets and links

The registry identifies each actual cover source, publication target, interactive source/dependencies, English introduction, tools, and evidence files. All covers are PNG; Day 05 is a lossless first-frame PNG from its approved GIF. Animations remain secondary links for Days 04, 05, 11, and 12. Day 12 keeps both snapshot PNGs in one card, each opening its own full-size map. All artwork is contained without cropping or stretching inside uniform cover frames.

Interactive cover links open the actual map in a new tab; static covers open their full-size image. Badges, alternative text, keyboard focus, hover feedback, light/dark contrast, and mobile taps are checked. The gallery itself has no runtime JavaScript or third-party dependency. Day 01's existing Leaflet/MapLibre/OpenFreeMap map still requires internet access; Days 02 and 10 embed their map data, while local Day 13 reads its ignored runtime files.

Publishing copies only explicitly registered safe assets; it never recursively copies daily output folders. `gallery-manifest.json` records the managed deployed assets. The pending Day 13 branch bypasses all map/art copying; it uses only `assets/13/publication-pending.svg` and `13/index.html`. Do not clear that status without the applicable agreement and a reviewed public bundle.

`--day NN` limits approved asset copying while regenerating the shared index. The generator also refreshes `scripts/maps_index_template.html` used by Day 01's older exporter. A small explicit list of superseded gallery-only copies is pruned; original daily assets are never removed. Lossless-conversion hashes and cleanup records stay under ignored `.work/`, not the deployment tree.
