# Original-language source fields

Project-authored documentation and explanatory text are English. The following third-party values remain unchanged; translating them would alter source evidence.

- `02/outputs/waterfront_walks_preview.html` and `docs/02/index.html` embed OSM `name:zh`, `name:zh-Hans` and `name:zh-Hant` tags for Dumbo Archway. These are original feature attributes, not Chinese interface instructions.
- `03/outputs/jc_city_boundary.geojson` and `data_raw/day03_playgrounds/jc_boundary_osm.json` retain the OSM Jersey City relation's multilingual names.
- `04/data/background.json` and original OSM XML/JSON/OSM snapshots in `data_raw/` retain multilingual street and place names, language-specific keys and original values.
- `data_raw/vintage_ny_harbor/*.html` are unchanged NYPL catalog snapshots, including the institution's original language-navigation labels. The original-language catalog content is source evidence.

No source tags, field names, geometries or approved Day01–05 map exports were translated or regenerated. Only project-authored report prose, explanatory evidence fields and their report-generating strings were changed to English.
