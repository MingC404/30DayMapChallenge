      字號
      1. 字號是該字在《廣韻》中的順序，例如《廣韻》第一個字「東」的字號為00001，依此類推至第25528號。
      2. 字號原則上為5位數，但當欲檢索的字號不滿5位數時，前方可不補零。例如輸入1或00001都可找到「東」字。
      3. 當輸入檢索的字號為1筆以上時，為了區別起見，字號之間需要加上半形逗號分隔，例如在「字號」的欄位中輸入「1,3,6」，代表檢索字號00001的「東」字、00003的「鶇」字，以及00006的「倲」字。
      4. 若要檢索某一區段的字，請輸入區段始尾之字號，中間以破折號隔開。例如輸入「1-6」，可檢索字號00001 至00006 的字。
      字
      1. 字是《廣韻》所收的25528個字。
      2. 將欲檢索的單字（或多個字）輸入於字的檢索欄位中，例如在字的欄位中輸入「千山鳥飛絕」。
      3. 在字的欄位中輸入1個字以上時，其結果顯示會依照輸入的順序排列。
      部件
      1. 部件是指字的一部分，當某些罕用字可能無法以輸入法打出時，即可利用部件進行檢索。例如輸入部件「龍」，可檢索出「籠」、「豅」、「朧」、「礱」等這些包含部件「龍」的字。
      2. 可以輸入多個部件以縮小檢索範圍，例如在部件欄位中輸入「龍口」，檢索結果會送出包含部件「龍」及部件「口」的字，並且縮小檢索結果。
      3. 當在檢索多個部件時，中間不需分隔符號，同時也無順序上的限制。因此在檢索欄位中輸入「龍口」或「口龍」，其檢索結果都是相同的。
      攝
      1. 此處的攝是指16攝。
      2. 請直接輸入攝的名稱，例如欲檢索《廣韻》中哪些字屬於「通」攝或「江」攝，請直接輸入「通江」。
      3. 若不確定攝名，可開啟輔助輸入視窗，點選攝名。
      4. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      聲調
      1. 聲調是指《廣韻》內的聲調，分為平、上、去、入。
      2. 請直接輸入欲查詢的聲調，例如欲檢索《廣韻》中哪些字屬於平聲或去聲，請直接輸入「平去」。
      3. 也可開啟輔助輸入視窗，勾選聲調。
      4. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      韻目
      1. 韻目是指《廣韻》的206個韻目。
      2. 請直接輸入欲檢索的韻目名稱，例如欲檢索《廣韻》中哪些字屬於平聲冬韻或上聲止韻，請直接輸入「冬止」。
      3. 若不確定韻目名稱，可開啟輔助輸入視窗，依平、上、去、入四個聲調，點選韻目。
      4. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      字母
      1. 字母為由《廣韻》歸納而出的42個字母。
      2. 請直接輸入欲檢索的字母名稱，例如欲檢索《廣韻》中哪些字屬於字母「幫」或「非」，請直接輸入「幫非」。
      3. 若不確定字母名稱，可開啟輔助輸入視窗，點選字母。
      4. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      開合
      1. 開合是指《廣韻》中韻母的開口或合口，請直接輸入「開」或「合」。例如，欲檢索《廣韻》中哪些字屬於「開口」，請直接輸入「開」。
      2. 也可開啟輔助輸入視窗，勾選開、合。
      3. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      等第
      1. 等第是指《廣韻》中韻母的等第，共分為4個等。
      2. 請直輸入中文數字的「一二三四」，或是阿拉伯數字的「1234」，例如欲檢索《廣韻》中哪些字屬於一或三等，可輸入「一三」或「13」。
      3. 也可開啟輔助輸入視窗，勾選等第。
      4. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      清濁
      1. 清濁是指《廣韻》中聲母的清濁，共分為4種情形：全清、次清、全濁、次濁。
      2. 請自行輸入中文，例如想檢索《廣韻》中哪些字屬於「全清」或「次清」，可直接輸入「全清,次清」。輸入1個以上的條件時，為求區隔，中間需以半形逗號分隔。
      3. 自行輸入中文時，若只輸入「清」，系統會自動檢索「全清」及「次清」，若只輸入「濁」，亦會自動檢索「全濁」及「次濁」。
      4. 也可開啟輔助輸入視窗，勾選清、濁。
      5. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      上字
      1. 上字是《廣韻》中的反切上字。
      2. 請直接輸入欲檢索的反切上字，例如想知道《廣韻》中哪些反切上字是「息」或「居」，請直接輸入「息居」。
      下字
      1. 下字是《廣韻》中的反切下字。
      2. 請直接輸入欲檢索的反切下字，例如想知道《廣韻》中哪些反切下字是「弓」或「良」，請直接輸入「弓良」。
      又音
      1. 又音是指《廣韻》中一個字的其他讀音，在《廣韻》原書中「又音」通常會標示為「又音某」。
      2. 請直接輸入欲檢索的又音，例如想知道《廣韻》中有哪些字的又音為「紅」或「東」或「蟲」，請直接輸入「紅東蟲」。
      又切
      1. 又切可檢索《廣韻》中一個字的其他切語，在《廣韻》原書中「又切」通常會標示「又某某切」。
      2. 又切原則上都是以2個字為1組，欲檢索1組以上的又切時，為求區隔，中間需以半形逗號分隔。例如，若想知道《廣韻》中哪些字的又切為「丁果」或「直珍」，請直接輸入「丁果,直珍」。
      3. 當只需檢索某個又切上字時，可用「*」代替不固定之又切下字，例如，只想檢索又切上字有「丁」的字時，請輸入「丁*」；同樣的，當只需檢索某個又切下字時，可用「*」 代替不固定之又切上字，例如只想檢索又切下字有「果」的字時，請輸入「*果」。
      4. 當只輸入一個字時，系統會視為只檢索又切上字，例如當只輸入一個字「丁」時，所得出的檢索的結果和輸入「丁*」是一樣的。
      韻部
      1. 上古音和中古音才有韻部欄位，韻部泛指在《廣韻》之前，對韻母的分類方式。
      2. 輸入方式為直接打韻部名稱，或使用輔助輸入視窗點選。
      3. 例如，若想檢索哪些字屬於「之」部，可在韻部欄位輸入「之」。
      4. 若不確定該聲韻系統有哪些韻部，可開啟輔助輸入視窗，點擊所需的韻部名稱。
      5. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      聲母
      1. 上古音、中古音、現代音都有聲母欄位。
      2. 輸入方式為直接打國際音標（IPA），或使用輔助輸入視窗點選。
      3. 例如，想檢索哪些字的聲母為「p」，可在聲母欄位輸入「p」；想檢索哪些字的聲母以「t」開頭，可輸入「t*」；想檢索哪些字的聲母以「ʰ」結尾，可輸入「*ʰ」；想檢索哪些字的聲母包含「s」，可輸入「*s*」。
      4. 若需要檢索某些不易輸入的國際音標，可開啟輔助輸入視窗，點擊所需的國際音標。
      5. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      韻母
      1. 上古音、中古音、現代音都有韻母欄位。
      2. 輸入方式為直接打國際音標（IPA），或使用輔助輸入視窗點選。
      3. 例如，想檢索哪些字的韻母為「a」，可在韻母欄位輸入「a」；想檢索哪些字的韻母以「i」開頭，可輸入「i*」；想檢索哪些字的韻母以「ŋ」結尾，可輸入「ŋ*」；想檢索哪些字的韻母包含「o」，可輸入「*o*」。
      4. 若需要檢索某些不易輸入的國際音標，可開啟輔助輸入視窗，點擊所需的國際音標。
      5. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
      調值
      1. 只有現代音有調值欄位。
      2. 輸入方式為直接打調值（阿拉伯數字）。
      3. 例如，想知道有哪些字的調值屬於55，可在調值欄位輸入「55」。
      調類
      1. 只有現代音有調類欄位。
      2. 輸入方式為直接打調類名稱，或使用輔助輸入視窗進行點選。
      3. 檢索規則與其他欄位略為不同，採取關鍵字搜尋，例如在粵語、清遠的調類欄位輸入「平」，可找出「陰平」及「陽平」的字。
      4. 也可開啟輔助輸入視窗，輸入調類。
      5. 在檢索欄位空白處點擊滑鼠左鍵2下，也可開啟輔助輸入視窗。
