## 几何与连通性核验

所有 OSM 步行 way 的引用节点均在本次 XML 中，不存在因节点遗漏产生的假断线。OSM API 会返回与查询框相交 way 的完整节点，因此 `osm_pedestrian_ways.geojson` 中福巴越岭的完整 way 会伸出研究框；不能把其总长当作园区网络长度。

本次拓扑统计以局部框 **[121.432, 24.708, 121.4435, 24.713]** 内的相邻节点边为准，不进行自动吸附、不补线、不把几何交叉直接当成连接节点：205 个节点、206 条唯一边、**2 个连通分量（190、15 节点）**，环路秩 3，约 **3336.74 m**。这说明已有环线基础，但整个选取网络尚未连为一体；外围零碎路段和筛选边界也会影响分量数，不能仅凭两个分量断言巨木主环必然中断。含 `trail_visibility=horrible` 的线须另核对，不能用来证明现况通行。

GPX 的实际累计点间平面距离约 **5852.50 m**，最大相邻采样步长 **84.57 m**，一个连续 XML 段。连续并不代表全程无 GPS 跳点、每条支线都走过或始终处于正确路线上。轨迹存在往返、停留漂移和重复经过，净路线长度应去重后再评估。没有按官网标称 4km 去拉伸或裁减真实数据。

## 路线长度与入口

官方最新折页同时出现几种数字：飽覽巨木路线卡为 **4000m**；底部巨木步道全程为 **3.3km**；游客中心到休憩平台为 **1100m**；管理站到游客中心的接近林道为 **2700m**。它们可能分别代表游程、路网或接近段，不能无说明相加或互相替换。本次未宣称已解释所有标称长度差异。

入口需要区分管理站售票入口、游客中心一侧步道起点、跳望之桥、休憩平台以及福巴越岭管制口。官方通讯点提供游客中心和部分重要节点参考，但没有提供每个入口和每一岔路的权威线网。园区网页上的统一景点坐标不得代替入口实测。

官方页当次显示福巴越岭受灾停开，另有期间休园公告；这与静态步道几何存在是两件事。研究资料不用于断言任何日期的通行条件，图上若延伸到该步道应另外核对最新公告。

## 能否形成可信的网络

**可以形成后续制图研究网络的基础，但当前还不能交付“完整、准确、可公开再利用的全支线网络”。** 建议采用 OSM 为可再利用的主几何，按官方导览图核对路线关系，以 GPX 查找疑似漏段。先确认 GPX 许可与所有支线去向，再逐段编辑并保留更改出处，不能凭视觉把两个端点任意连直线。

下一步具体需要核对：游客中心接近段与道路/步道分类；24 号终端支线；13 号双树点附近的岔路；官方彩色路线上的全部分支对应；两个 OSM 分量是否在地图目标范围内需要实际连接。即使构建出连续图，也须继续保留来源和未验证精度说明。
