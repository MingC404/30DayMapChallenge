# 地形数据

## 20m DTM 的获取与授权

[指定数据集 178729](https://data.gov.tw/dataset/178729)目前是 2026 年版，免费、政府资料开放授权条款第 1 版。页面下载项的描述写了 DSM，与页面标题 DTM 不一致；本次下载的目录 CSV 列出的是 DEM 包，因此保留这一元数据问题，后续仍需检查实际文件。该数据的“2026”是发布版本，不保证每幅地形均测于 2026 年。

已保存 `sources/dtm_2026_catalog.csv`（5,108 bytes）。CSV 是链接目录，不是高程点。它提供县市分幅 ZIP、全国不分幅 ZIP 及 schema ZIP。桃园链接为：

<https://www.tgos.tw/MDE/VirtualDir_TC/Product/6c64edb5-09e8-4d5a-8a15-ea5a77440d48/分幅_桃園市20MDEM(2026).zip>

无需登录的公开下载链接存在，但本环境请求桃园包尾部 100KB 及 schema 包均收到 **HTTP 403**。也试过完整百分号编码路径，结果相同；没有下载台湾全国 ZIP，也没有下载整个桃园包。`taoyuan_range_retry.headers` 等保留响应证据；HTTP 错误正文不是 DEM。

[公开下载器维护者的实测说明](https://github.com/outdoorsafetylab/moidemd#建置環境)报告 TGOS 对台湾以外 IP 的地理限制，与本次 403 相符，但我们没有独立证明本次拒绝的具体原因。不能因此断言资料不存在或须另行申请。合理的后续方法是在合法可访问的台湾环境获取目标县市包，或请提供者给单幅开放资料；不应下载来源不明的高精度资料。

[DTM 加值平台](https://dtm.moi.gov.tw/)声明 20m 为开放资料。其分析 UI 实测跳转登录页；保存的 `dtm_openapi.json` 的路径均含 `api_key`，输入说明为 WGS84。因此“开放数据无需申请”不等于“所有分析 API 均匿名可调用”。本次没有取得 key 或调用分析 API，也未将 hillshade API 图片当成原始 DEM。

## 拉拉山目标图幅与范围

拟定研究 AOI：WGS84 **[121.425, 24.700, 121.450, 24.720]**（west, south, east, north），覆盖游园巨木群及地形缓冲；这是研究框，不是官方园区界。约对应 EPSG:3826 的西南 (293003.34, 2732616.34)、东北 (295525.70, 2734839.60)，这些只是两角转换值，不是精确投影外包框。

从[官方 1:5000 参考索引 115926](https://data.gov.tw/dataset/115926)下载完整的小型索引 SHP ZIP（314,437 bytes），检查 `.prj`、读取图框，输出 `data/reference_sheets_5k.geojson`：

| 参考图幅 | 图名 | 官方图框在 EPSG:3826 的外包框 E_min / N_min / E_max / N_max |
|---|---|---|
| **96222018 / 9622-II-018** | 拉拉山（二） | 293810.27 / 2732434.29 / 296348.70 / 2735211.50 |
| **96222017 / 9622-II-017** | 拉拉山（三） | 291281.10 / 2732426.53 / 293819.02 / 2735203.27 |

巨木群核心在 018；游客中心、入园接近段和西侧缓冲跨到 017。**如只取这次研究框，应以 017+018 为起始检索目标**。这是经官方参考图框确定的地理定位，不是已检查 2026 DTM ZIP 内部目录后的覆盖保证。不同数据产品的分幅命名、边界裁切和实际 NoData 仍需对照 DTM 头文件。官方参考索引明确面向电子地图、国土利用及正射影像，不能冒称 DTM 本身的有效像元索引。

1:25000 地形图索引中的「巴陵 9622-II-NE」是较大比例尺层级的参考图名；它不是 20m DTM 单幅文件名。已避免用这个大图号代替 5000 分幅号。

## CRS、分辨率、格式及待验项目

| 项目 | 已知及证据级别 |
|---|---|
| 格网间距 | 官方页面明确为 **20m**；是格点间距，不是水平或垂直误差保证。 |
| 平面 CRS | 官方目录写 **TWD97(N、E、H)**；台湾本岛工作投影应为 **TM2 121 / EPSG:3826**。必须避免把米制坐标当成 TWD97 经纬度 EPSG:3824。目标原文件头未取得，最终确认仍待进行。 |
| 垂直基准 | 公开下载器维护者报告为 **TWVD2001 正高**；本次尚未以目标图幅头独立核验，不能把其当成已验字段。 |
| 分幅格式 | 官方目录分发 ZIP；常见为 ASCII XYZ/E,N,H 点及配套头文件。schema ZIP 本次 403，**目标桃园包内部实际扩展名、字段顺序、NoData 未核实**。读取时不能仅按目录的 N/E/H 字样猜列顺序。 |
| 不分幅格式 | [公开下载器源码](https://github.com/outdoorsafetylab/moidemd/blob/master/scripts/fetch-dem.py)记录 2026 本岛包为 TIFF+TFW，Float32 等细节来自维护者说明；本次未下载全国文件来验证。不是所有分幅包都可以据此称为 GeoTIFF。 |
| 授权 | 政府资料开放授权条款第 1 版；后续成果注明内政部地政司、版本和授权，并标明派生处理。 |

## 地形派生可行性（方法判断，未实际运算）

Hillshade：适合。20m 足够表现山谷、坡向和较大山脊；建议多方向晕渲加少量水墨质感，不把林冠阴影当成地面地形。需要先拼接图幅、裁切并保留几百米边界缓冲。

Contours：适合。可先试 20m 等高距、100m 主曲线；10m 等高距在算法上可插值，但不等于地形拥有 10m 空间分辨率。最终密度随输出比例尺决定，不应用树根、栈道等微地形的表现精度解释它。

Ridge lines：可从平滑高程、曲率、地形位置或反地形汇流提取候选山脊，再人工核对。它们是模型派生的地形结构，不是原始测量线；20m 不足以保证狭小山脊和步道边坡的精细位置。没有实际 DEM 时，本次只判断可行，不输出任何山脊线。

## 更高分辨率替代调查

[官方供图平台](https://applydtm.moi.gov.tw/)及[FAQ](https://applydtm.moi.gov.tw/FAQ.php)将 5m 以下高精度 DTM 列为管制资料，存在机关或特定学术专案申请通道，**不属于本项目可自由公开下载并使用的替代底图**；1m API 也受限制。

国网中心 [ODC dem_10m_taiwan](https://twodc.colife.org.tw/products/dem_10m_taiwan)虽然名称为台湾 10m，本次页面 footprint 实际只有一个中部资料覆盖，纬度约 23.697–24.219，**不覆盖 24.71°N 的拉拉山**，因此排除，不能据产品名认定全岛都有 10m。

本次没有验证到**同时满足拉拉山覆盖、优于 20m、合法开放再利用、可实际取得**的替代 DTM。也未把更密的等高线、重采样栅格或插值地形当作更高分辨率的原始测量。30m 全球模型只能作为较粗后备，不满足“更高分辨率”的要求。
