# Day 18 — AI-assisted Shanshui 参考素材

本目录仅为艺术底图生成及后续GIS叠加准备参考，不是最终地图。复用已确认的真实DSM、相机、画面裁切及深度测试；没有重新下载数据，没有新开发笔墨算法。

- `terrain_reference.png`：1800×2025、8:9竖幅，RGB。米白背景与简单灰度地形阴影，无皴擦、纸纹、树、步道、文字或印章。前景自然延伸到画布底部及左右边缘；保留远景轮廓。
- `gis_overlay_reference.png`：相同1800×2025画布、RGBA透明背景。红色小针标记为15个既有OSM候选位置，赭色为原参考GPX，蓝色十字为既有官方通讯标示点/设施定位锚点。无标题、图例或来源文字。符号只是定位工具，不是绘制的古树。
- `projection_parameters.json`：完整相机、像素坐标原点、投影公式、米到像素比例、输入/输出哈希、15个树根XYZ及对应像素坐标、3个锚点、遮挡后可见像素数、步道显示处理。
- `export_references.py`：可复现导出脚本，使用Day18现有Python依赖。运行 `python -B 18/ai_reference/export_references.py`。不联网，不产生中间图片或缓存。

相机仍为azimuth315°、elevation18°、vertical exaggeration1.20×、正交视窗高度1500m；target与偏轴画面定位不变。地形三角形、深度缓冲和山体遮罩哈希均与已确认的A实验一致；并验证前景覆盖整个底边及左右下半边。底图没有悬浮矩形网格的外边缘。

叠加层**保留真实地形遮挡**。15个候选均保留原XYZ并参与投影，实际有14个小针仍有可见片段；另1个被地形完全遮挡，不以透视穿透方式强行显示。参数文件保留其位置与可见性。三个官方锚点为游客中心、休憩区、达观亭，其中达观亭被地形遮挡；其余两个蓝色十字可见。它们的原始坐标角色是通讯标示点/设施，不是逐树测量坐标。

针标的底部位于原候选树根，22m符号杆沿用原场景的定位标记高度，不是测量树高。GPX沿用现有显示规则：sigma2.0的有界平滑、最大平面偏移4m、端点和顺序保留，再贴合相同三角面并深度测试。原始GPX与候选数据不改动。

两张PNG可按左上角原点直接重合，后续不要单独缩放、移动或裁切其中一层。艺术底图生成时应保持画幅与地形轮廓；若生成过程改变了山脊、谷地或透视，不能只凭尺寸相同就声称GIS与画面仍精确对齐。

数据仍为Copernicus GLO-30 DSM（含林冠），不是MOI裸地DTM。候选树位精度未验证，GPX为原公开游客实录；沿用 `../NOTICE.md` 及research中的来源/许可记录。本轮只生成参考素材，未制作AI艺术底图、最终地图、GIF，未更新Gallery，未commit或push。既有研究和代码保持不变。
